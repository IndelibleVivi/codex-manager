# Codex 管理器

> 看见、管理、清理你的 Codex 本地配置——防止 Codex 在电脑里堆垃圾的可视化小工具。

![截图](docs/screenshot.png)

## 这是什么？

Codex 用久了会在电脑里堆积几百上千条 md 文件、测试残留、缓存副本，而它的配置（md 和 skill）藏得很深，平时根本看不见。

这个工具就干两件事：

1. **看得见** —— 配置、技能、记忆全部可视化分组，每个文件是干嘛的都用人话标注
2. **管得住** —— 垃圾一键清理、文件看/改/删、删错了有回收站（7 天自动清理）

## 功能

- 📂 **文件管理**：分组浏览（配置文件 / Skills / 记忆系统 / 临时垃圾 / 历史记录 / 系统托管），原地展开，人话解释
- ✏️ **编辑与删除**：在线编辑保存即生效，删除进回收站
- 🗑 **回收站**：恢复 / 彻底删除 / 7 天自动清理
- 🧹 **一键清理**：临时垃圾、历史记录整组清理
- 🔍 **md 查重**：按内容找重复 md
- ➕ **新建 Skill**：固定格式模板 + 保存时格式校验（错误红字提示），保存即生效
- 🌐 **翻译**：英文文件一键翻译成中文预览（需要本机 127.0.0.1:10100 有 AI 代理，没有则此功能不可用，其他功能不受影响）
- 📊 **库存仪表盘**：一键扫描 ~/.codex 出体检报告，垃圾超标亮红灯

## 安装（30 秒）

### Windows

1. 安装 Python 3（[python.org](https://python.org)，安装时勾选 **Add python.exe to PATH**）
2. 下载本仓库，解压「Codex管理器」文件夹到任意位置
3. 双击文件夹里的 **「① 双击我安装.bat」** → 桌面出现两个图标

### macOS

1. 确认终端里可以运行 `python3 --version`；没有的话先安装 Python 3
2. 下载本仓库，解压「Codex管理器」文件夹到任意位置
3. 双击 **「打开 Codex 管理器-macOS.command」** 或 **「打开 Codex 库存仪表盘-macOS.command」**

macOS 管理器默认以**完整管理模式**启动，和 Windows 一样可以编辑、删除、恢复、一键清理和新建 Skill。删除及整组清理前都会确认，内容先进入隔离区；但直接编辑保存不会自动备份。第一次打开若被 macOS 拦截，可在 Finder 里右键该文件并选择「打开」。

## 使用

- **Codex 管理器**（桌面图标）：主工具，打开网页版管理界面
- **Codex 库存仪表盘**（桌面图标）：一键扫描出报告，红灯就该清理了
- **macOS 管理器**（`.command`）：打开完整网页版管理界面，支持编辑、清理和恢复
- **macOS 库存仪表盘**（`.command`）：只扫描 `~/.codex`，在系统临时目录生成报告后打开

想先只读检查，或对一份测试副本操作，可以显式指定目录：

```bash
python3 "Codex管理器/零件箱/Codex配置管理器.py" --root "/你的测试目录/.codex" --read-only
```

详细教学见 [Codex管理器-使用教学.md](Codex管理器-使用教学.md)

## 堵根源（推荐配合）

工具是扫帚，更要堵住源头。把下面这段加进你的 `AGENTS.md`：

```
## 文件卫生规则
- 临时文件（测试脚本、草稿、一次性产物）只准写到系统临时目录
  （Windows: %TEMP%，Linux/Mac: /tmp），禁止写进项目目录和 ~/.codex。
- 任务收尾前必须删掉所有非交付物，只留下用户明确要求的交付文件。
- 除非用户明确要求，禁止在项目里生成总结/报告类的 .md 文件。
- commit 前先 git status 自查，确认没有混入临时文件。
```

## 卸载

删掉文件夹 + 桌面两个图标即可，无任何残留。
